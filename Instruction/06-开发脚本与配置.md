# 开发脚本与配置

## 模块概述

本文档说明项目根目录下的开发辅助脚本和配置文件，包括启动脚本、构建脚本、代码风格配置等。

## 开发环境启动脚本

### start-dev.bat（CMD 版本）

适用于 Windows CMD 环境，同时启动三个服务：

```batch
@echo off
setlocal
cd /d "%~dp0"

start "AnythingLLM Server" cmd /k "cd /d %~dp0server && yarn dev"
start "AnythingLLM Frontend" cmd /k "cd /d %~dp0frontend && yarn dev"
start "AnythingLLM Collector" cmd /k "cd /d %~dp0collector && yarn dev"
```

- 自动定位到脚本所在目录
- 分别在新窗口中启动 Server、Frontend、Collector
- 每个服务运行在独立的 CMD 窗口中

### start-dev.ps1（PowerShell 版本）

适用于 PowerShell 环境，功能与 bat 版本相同：

```powershell
Start-Process powershell -ArgumentList "-NoExit", "-Command", "Set-Location '$PSScriptRoot\server'; yarn dev"
Start-Process powershell -ArgumentList "-NoExit", "-Command", "Set-Location '$PSScriptRoot\frontend'; yarn dev"
Start-Process powershell -ArgumentList "-NoExit", "-Command", "Set-Location '$PSScriptRoot\collector'; yarn dev"
```

- 启动后显示各服务的访问地址：
  - Frontend: http://localhost:3000
  - Server: http://localhost:3001
  - Collector: http://localhost:8888

## 构建脚本

### build-skill-zip.ps1

PowerShell 脚本，用于将 skill 模板文件夹打包为 zip 文件：

**参数**:
- `-Source`: 源文件夹路径，默认 `.\skill-template\standard-non-mcp-skill`
- `-Output`: 输出 zip 路径，默认 `.\skill-template\dist\standard-non-mcp-skill.zip`

**执行流程**:
1. 解析源路径
2. 创建输出目录（如不存在）
3. 删除已存在的目标 zip 文件
4. 调用 `Compress-Archive` 生成 zip
5. 输出结果路径

**使用方式**:
```powershell
# 使用默认参数
powershell -ExecutionPolicy Bypass -File .\build-skill-zip.ps1

# 自定义参数
powershell -ExecutionPolicy Bypass -File .\build-skill-zip.ps1 -Source .\my-skill -Output .\dist\my-skill.zip
```

## package.json Scripts 说明

根目录 `package.json` 中定义的脚本命令：

| 命令 | 说明 |
|------|------|
| `yarn setup` | 一键安装所有依赖、复制环境变量文件、初始化数据库 |
| `yarn setup:envs` | 仅复制 .env.example 为 .env 文件 |
| `yarn dev:server` | 启动后端开发服务器 |
| `yarn dev:frontend` | 启动前端开发服务器 |
| `yarn dev:collector` | 启动文档收集器 |
| `yarn dev:all` | 一键启动所有服务（调用 start-dev.ps1） |
| `yarn start:dev` | 同 `dev:all` |
| `yarn prisma:generate` | 生成 Prisma 客户端 |
| `yarn prisma:migrate` | 执行数据库迁移 |
| `yarn prisma:seed` | 执行数据库种子数据 |
| `yarn prisma:setup` | 生成 + 迁移 + 种子（完整数据库初始化） |
| `yarn prisma:reset` | 清空数据库文件并重新迁移 |
| `yarn prod:server` | 生产模式启动后端 |
| `yarn prod:frontend` | 生产模式构建前端 |
| `yarn lint` | 对所有子项目执行 lint 修复 |
| `yarn lint:ci` | CI 环境中只检查不修复 |
| `yarn test` | 运行测试（Jest） |
| `yarn translations:verify` | 验证翻译文件完整性 |
| `yarn translations:normalize` | 规范化英文翻译文件 |
| `yarn translations:prune` | 清理未使用的翻译键 |
| `yarn translations:create` | 创建翻译（执行 lint） |

## 代码风格配置

### .editorconfig

统一不同编辑器的编码风格设置（缩进、换行符、编码等）。

### .prettierrc / .prettierignore

Prettier 代码格式化配置：
- `.prettierrc`: 格式化规则（引号、分号、缩进等）
- `.prettierignore`: 排除不需要格式化的文件

### eslint.config.js

ESLint 代码质量检查配置，每个子项目（server、frontend、collector）各有独立的 eslint 配置。

## Git 配置

### .gitignore

排除以下类型文件：
- `node_modules/`
- `.env` 文件（保留 `.env.example`）
- 构建产物
- IDE 配置文件
- 系统文件

### .gitattributes

定义文件在 Git 中的行为（如换行符处理）。

## Node.js 版本管理

### .nvmrc

指定项目要求的 Node.js 版本，确保团队成员使用统一版本。每个子项目（server、frontend、collector）都有各自的 `.nvmrc` 文件。

**要求**: Node.js >= 18

## 环境变量配置

各子模块的 `.env.example` 文件提供了所需环境变量的模板：

### server/.env.example
服务器核心配置，包含：
- 数据库连接
- LLM 提供者密钥
- 向量数据库配置
- 嵌入模型配置
- 认证配置
- 其他服务集成密钥

### frontend/.env.example
前端配置，通常包含：
- API 服务器地址

### collector/.env.example
收集器配置，通常包含：
- 服务端口
- 日志级别

## 开发依赖

根项目的开发依赖：
- **concurrently**: 并行运行多个命令
- **jest**: 测试框架
