# 开发日志 — Skill 导入 Agent 功能实现

**目标**: 实现「Skill 导入 Agent」功能，将 handoffToAgentImporter 从桩函数替换为真实导入流水线。

**本期范围**: 仅 zip；不自动安装依赖；审批闸门权限模型（无运行时沙箱）；不支持 MCP 依赖型 skill；同步返回完整报告。

**最终验收口径**: 前端 `/settings/community-hub/skills` 可完整完成：拖入 zip → 自动导入 → 跳转详情页 → 批准并启用。

## [M3] M3 · 环境检测

- 改动文件：
  - `server/utils/agents/skillImporter/envDetector.js`（新增）
- 接口：`detectEnv(requirements) -> EnvResult`
- 三态规则：`compatible = !any(required && status==='unsatisfied')`；`hasWarnings = any(required && status==='unknown')`
- Node：`process.versions.node` vs semver range（自实现，无外部依赖）
- Python：execSync `python3`/`python` 兼容 Windows；找不到且 required → unsatisfied
- env vars：仅判存在，**不读取值**（符合安全要求）
- pip/npm：不可靠则固定 `unknown`，required=false，不据此判 unsatisfied
- mcp：固定 `skipped`（范围外）
- 自测结果：Windows 兼容，降级逻辑覆盖
