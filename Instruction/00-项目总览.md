## 项目简介

AnythingLLM 是一个将私有文档转化为聊天机器人的解决方案，使用现成的工具和商业可行的 AI 技术。本项目在此基础上扩展了一个 **SKILL Store**（技能商店）功能，允许团队成员通过上传 zip 压缩包的方式，将非 MCP（Model Context Protocol）技能包添加到本地商店中，进行验证、预览和安装。

## 架构概述

项目采用前后端分离架构，由三个主要服务组成：

```
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│   Frontend    │     │    Server     │     │   Collector   │
│  (React/Vite) │────▶│  (Express.js) │────▶│  (Express.js) │
│  端口: 3000    │     │  端口: 3001    │     │  端口: 8888    │
└───────────────┘     └───────────────┘     └───────────────┘
```

- **Frontend（前端）**: 基于 React + Vite 的单页应用，提供用户界面
- **Server（后端服务器）**: 基于 Express.js 的 API 服务器，处理业务逻辑
- **Collector（文档收集器）**: 独立的文档处理微服务，负责解析各类文件格式

## 开发环境设置

### 一键设置

```bash
yarn setup
```

此命令执行以下操作：
1. 安装 server、collector、frontend 各自的依赖
2. 复制 `.env.example` 文件为相应的 `.env` 配置文件
3. 生成 Prisma 客户端
4. 运行数据库迁移
5. 执行数据库种子数据初始化

### 启动开发环境

**方式一：分别启动**
```bash
yarn dev:server     # 启动后端服务器（端口 3001）
yarn dev:frontend   # 启动前端开发服务器（端口 3000）
yarn dev:collector  # 启动文档收集器（端口 8888）
```

**方式二：一键启动所有服务（Windows）**
```bash
yarn dev:all
# 或
start-dev.bat
```

### 重要提示

在启动服务之前，必须先填写 `server/.env.development` 中的配置信息，否则代码无法正常执行。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | React 18 |
| 构建工具 | Vite |
| 样式 | Tailwind CSS |
| 路由 | React Router v6 |
| 国际化 | i18next |
| 后端框架 | Express.js |
| 数据库 | SQLite (via Prisma ORM) |
| 文件上传 | Multer |
| 向量数据库 | 支持多种（Pinecone, Chroma, Qdrant, Milvus, LanceDB 等） |
| LLM 提供者 | 支持多种（OpenAI, Anthropic, Ollama 等） |
| 文档解析 | LangChain, pdf-parse, mammoth 等 |
