# Example Local Skill

Use this template as the entry document for a non-MCP skill package.

## What this skill should do

- Describe the task this skill is meant to solve
- Explain the expected workflow for the agent
- Keep the instructions concrete and short

## Suggested structure

1. State the goal
2. Describe the decision rules
3. Mention important files or references
4. Add short examples if the skill is fragile

## Example prompt patterns

- "Use this skill to process a local task"
- "Apply the skill workflow to this file"

## Packaging notes

- Keep this file as `SKILL.md`
- If you rename it, also update `entryFile` in `skill.json`
- This template is intended for the current non-MCP upload flow
